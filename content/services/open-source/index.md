We strongly believe in Open Source. Most of our training courses are built on open-source technologies such as Docker, Kubernetes, Helm, Go, and so on. Our standard course content, samples, and tools that we have built to deliver these courses, are all open source. They are available under the MIT License on [GitHub](https://github.com/rajware).

## Tools for Rajware trainings

We have built a set of open source tools that we use in our trainings. You can use these too, to set up a learning environment. The list includes:

* [kutti](https://github.com/kuttiproject/kutti) - a cross-platform tool that helps set up Kubernetes clusters on top of VirtualBox, Hyper-V and Lima. kutti is part of a larger project to create a custom Kubernetes environment, which includes a storage provisioner and a CNI network plugin. Access the kutti project [here](https://github.com/kuttiproject).
* [matsya](https://github.com/rajware/dockercourse-image) - a custom virtual machine used to teach containerization in depth, available on VirtualBox and Hyper-V, and built with Alpine Linux and Docker. 
* [bhringa](https://github.com/rajware/ebpfcourse-image) - a custom virtual machine used to teach eBPF programming in depth, available on VirtualBox and Hyper-V, and built with Alpine Linux, Docker and the LLVM/clang compiler toolset.

## General Tools

We also general-purpose tools, for both fun and productivity. The list includes:

* [voxel-dockerclient](https://github.com/rajch/voxel-dockerclient) - an experimental tool that provides a videogame-like interface to play with Docker.
* [ms-forms-diagram](https://github.com/rajch/ms-forms-diagram) - a Chrome and Edge browser extension that can draw a diagram to document branching logic in Microsoft Forms forms.
* [numberstowords](https://github.com/rajch/numberstowords) - a JavaScript library to convert numbers to words. Supports both international and Indian conventions.

## Tools for MaxOffice
We work with our partner concern, MaxOffice Services Private Limited to build open source tools. These can be found at the [MaxOffice GitHub organisation](https://github.com/maxoffice).

## Weave Net

Weave Net is a software networking product for connecting Docker containers across multiple hosts. It can also be used as a CNI plugin for Kubernetes. Weave Net was developed by Weaveworks. When Weaveworks shut down, our consultant Raj Chaudhuri forked the project and took on the responsibility of maintaining and updating Weave Net.

The Rajware-maintained fork of Weave Net can be found [here](https://github.com/rajch/weave).
